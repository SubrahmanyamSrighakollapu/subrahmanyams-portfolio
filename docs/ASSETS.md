# Asset provenance

## Supplied screenshots

The user supplied the five portfolio screens under `docs/design-references/`. Project previews, the four interest photographs, the project laptop image, the mountain journey, mountain CTA and location-map artwork were extracted from those screens and encoded as local WebP files. They retain the reference artwork and should not be treated as newly captured production screenshots. The source previews are small; original project screenshots will improve high-density display quality.
